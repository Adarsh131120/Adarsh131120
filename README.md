A modern platform where developers can showcase their trending projects. Built with the MERN stack, featuring:
- Seamless project uploads with Cloudinary integration
- Beautiful UI designed with Tailwind CSS
- Real-time project discovery and trending algorithms

- Persistent data storage using C++ file handling (fstream).

- Optimized C++ implementations
